## What it is

A fast, single-page marketing site for **AetherFlow**, an AI automation & machine-learning agency. It presents the agency's offering and captures qualified leads through a structured enquiry form.

**Sections:** hero, services, "why choose us", portfolio, expertise, and a call-to-action contact form with a categorized service selector.

## Tech

- **Static HTML / CSS / JavaScript** — no build step, loads instantly, trivially cacheable on a CDN.
- **[Netlify](https://www.netlify.com/)** — hosting plus serverless **form handling** (the contact form submits to Netlify Forms, no backend required).

## Run locally

It's a static page — just open `index.html` in a browser, or serve the folder:

```bash
# any static server works
python -m http.server 8000   # then visit http://localhost:8000
```

## Deploy

Connect the repository to Netlify (or drag-and-drop the folder into the Netlify dashboard). Form submissions appear under **Forms** in the Netlify site dashboard.
